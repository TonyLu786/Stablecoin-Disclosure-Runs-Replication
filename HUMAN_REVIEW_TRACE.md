# Researcher Review Trace

This repository preserves researcher-review points needed for public replication:

- rule-freeze records in `02_manual_coding/RQI_DII_rules_v1_freeze.md`;
- coding-dispute records in `02_manual_coding/coding_disputes_v1.md`;
- event-classification review files in `02_manual_coding/`;
- governance and review protocols in `00_admin/`.

The public package does not redistribute raw third-party source captures. Source identifiers, URLs, access dates, and review flags are retained in structured tables.
