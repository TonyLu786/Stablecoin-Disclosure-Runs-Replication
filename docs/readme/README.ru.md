# Условная прозрачность на рынках стейблкоинов

Этот репозиторий является публичным пакетом данных и кода для воспроизведения исследования раскрытия резервов стейблкоинов с проверяемой источниковой базой. Он объединяет индексы раскрытий эмитентов, проверенное исследователем кодирование RQI/DII, дневные рыночные панели, диагностику событийных окон, результаты проверок устойчивости и контроль границ утверждений.

Публичная версия содержит только материалы, которые можно проверить, повторно запустить и расширить. Включены только данные, код, документация и производные результаты воспроизведения.

## Быстрый старт

```powershell
python -m pip install -r requirements.txt
python scripts\check_public_release.py
python scripts\run_public_replication.py --mode smoke
```

Основные команды:

```powershell
python scripts\run_public_replication.py --mode analysis
python scripts\run_public_replication.py --mode all
```

PDF, сохраненные веб-страницы и копии сторонних источников не распространяются в публичном пакете. Публичные файлы сохраняют URL, даты доступа, статус источников, идентификаторы событий и отметки проверки. Результаты следует читать как пилотную диагностику.
