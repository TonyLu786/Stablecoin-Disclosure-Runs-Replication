# Claim Boundary

This package supports:

- data pipeline feasibility;
- reproducible source and coding architecture;
- Reserve Quality Index and Disclosure Information Intensity Index construction;
- pilot baseline and event-window diagnostics;
- source-quality tiering and claim-boundary documentation.

This package does not support:

- final causal effect claims;
- market-wide disclosure generalization;
- policy counterfactuals;
- investment, legal, or regulatory advice;
- unrestricted use of archive-pending source rows in inferential claims.

All results should be read as pilot diagnostics unless later source upgrades and robustness checks justify stronger wording.
